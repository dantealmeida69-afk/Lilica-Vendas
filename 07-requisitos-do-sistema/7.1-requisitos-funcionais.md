# 7.1 requisitos funcionais

| ID   | Funcionalidade                  | Descrição                                                                                | Prioridade |
| ---- | ------------------------------- | ---------------------------------------------------------------------------------------- | ---------- |
| RF01 | Login e perfis                  | Autenticar usuários com perfil Administrador ou Vendedor.                                | Alta       |
| RF02 | Cadastro de produtos            | Criar, editar e inativar produtos com categoria, preço e estoque mínimo.                 | Alta       |
| RF03 | Cadastro de categorias          | Organizar produtos por categoria.                                                        | Média      |
| RF04 | Cadastro de clientes            | Cadastrar e consultar clientes.                                                          | Alta       |
| RF05 | Registro de venda               | Criar pedido com um ou mais itens, calculando subtotais e total.                         | Alta       |
| RF06 | Validação de estoque            | Impedir a venda de quantidade maior que o estoque disponível.                            | Alta       |
| RF07 | Pagamento                       | Registrar a forma de pagamento (PIX, dinheiro, cartão) e o status.                       | Alta       |
| RF08 | Baixa automática de estoque     | Reduzir o estoque a cada venda e registrar a movimentação.                               | Alta       |
| RF09 | Cancelamento de pedido          | Cancelar pedido e devolver os itens ao estoque.                                          | Média      |
| RF10 | Entrada de estoque              | Registrar reposição de produtos.                                                         | Alta       |
| RF11 | Alerta de estoque baixo         | Listar produtos com estoque igual ou abaixo do mínimo.                                   | Média      |
| RF12 | Consulta de vendas              | Filtrar pedidos por período, cliente, vendedor e status.                                 | Alta       |
| RF13 | Relatórios                      | Vendas por período, produtos mais vendidos, faturamento por vendedor e ticket médio.     | Alta       |
| RF14 | Histórico do cliente            | Exibir as compras anteriores de cada cliente.                                            | Média      |
| RF15 | Comprovante                     | Gerar comprovante da venda para o cliente.                                               | Baixa      |
| RF16 | Assistente Lilica (IA)          | Gerar resumo do período e sugestões de reposição e de ação, com base em dados agregados. | Média      |
| RF17 | Identificação de conteúdo de IA | Rotular textos gerados por IA e deixar claro que são sugestões.                          | Média      |
