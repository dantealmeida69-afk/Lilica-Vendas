# 7.2 requisitos nao funcionais

| ID    | Categoria             | Descrição                                                                       | Como verificar                        |
| ----- | --------------------- | ------------------------------------------------------------------------------- | ------------------------------------- |
| RNF01 | Usabilidade           | Concluir uma venda em poucos passos, sem treinamento.                           | Teste com usuários reais.             |
| RNF02 | Responsividade        | Funcionar em celular e computador.                                              | Teste em telas diferentes.            |
| RNF03 | Desempenho            | Consultas e vendas respondem em tempo adequado. 🔲 Definir meta (ex.: até 2 s). | Medição nos testes.                   |
| RNF04 | Integridade dos dados | Nenhuma venda pode deixar o estoque negativo ou o total incorreto.              | Restrições do banco e testes.         |
| RNF05 | Precisão monetária    | Valores em reais com duas casas decimais, sem erro de arredondamento.           | Uso de `NUMERIC` e testes.            |
| RNF06 | Segurança             | Senhas com hash, controle de acesso por perfil e conexão HTTPS.                 | Testes de acesso e revisão de código. |
| RNF07 | Privacidade (LGPD)    | Coletar só os dados necessários dos clientes e proteger o acesso.               | Revisão do fluxo de dados.            |
| RNF08 | Confiabilidade        | Operações de venda são atômicas (ou tudo é gravado, ou nada).                   | Uso de transações e testes de falha.  |
| RNF09 | Backup                | Cópia periódica do banco. 🔲 Definir rotina.                                    | Teste de restauração.                 |
| RNF10 | Transparência da IA   | Sugestões da IA identificadas como tal.                                         | Inspeção das telas.                   |
| RNF11 | Manutenibilidade      | Código versionado e documentado.                                                | Revisão por pull requests.            |
| RNF12 | Acessibilidade        | Bom contraste, letras legíveis e botões grandes.                                | Checklist de acessibilidade.          |
