# README

{% hint style="warning" %}
**Rascunho v0.1 (28/09/2026).** O conceito do sistema foi montado a partir de uma suposição: _"Lilica Vendas" é um sistema web de gestão de vendas para pequeno comércio_. Tudo que estiver marcado com 🔲 precisa ser confirmado ou preenchido pelo grupo.
{% endhint %}

**Lilica Vendas** é um sistema web para registrar vendas, controlar estoque e acompanhar o desempenho do negócio, com um **assistente de IA** que transforma os números em resumos simples e sugestões práticas.

**Vendedor registra a venda → estoque atualiza sozinho → dono acompanha os resultados → IA sugere o que fazer.**

## Como este livro está organizado

O GitBook conta a evolução do projeto, do problema à demonstração para a banca:

**PROBLEMA → USUÁRIO → SOLUÇÃO → IA → PROTÓTIPO → DESENVOLVIMENTO → TESTES → MELHORIAS → MVP → BANCA**

Ele **não é escrito só no final**: cada Revisão Técnica (RT) acrescenta conteúdo, e o histórico de versões comprova a evolução.
