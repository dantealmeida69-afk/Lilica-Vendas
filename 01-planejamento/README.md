# 01 planejamento

## 1. Objetivo

Organizar o desenvolvimento do sistema Lilica Vendas em etapas, mantendo a modelagem alinhada à Entrega 2 de Modelagem do Sistema.

## 2. Etapas do projeto

| Etapa | Atividade              | Entregável                                                                        | Situação          |
| ----- | ---------------------- | --------------------------------------------------------------------------------- | ----------------- |
| 1     | Levantamento dos dados | Entidades, atributos e necessidades do sistema                                    | Concluída         |
| 2     | Modelagem conceitual   | DER com cardinalidades                                                            | Concluída         |
| 3     | Modelo lógico          | Tabelas, PKs, FKs, tipos e restrições                                             | Concluída         |
| 4     | Implementação do banco | Script SQL de criação das nove tabelas                                            | Em andamento      |
| 5     | Povoamento             | Dados de teste para clientes, produtos, vendas, pagamentos, encomendas e repasses | Em andamento      |
| 6     | Consultas SQL          | Consultas para conferência e relatórios                                           | Em andamento      |
| 7     | Testes                 | Testes funcionais, de banco, integração e validação                               | Em andamento      |
| 8     | Correções              | Registrar erros encontrados e respectivas correções                               | Conforme execução |
| 9     | Documentação final     | Consolidar modelagem, SQL, testes e resultados                                    | Pendente          |

## 3. Organização das prioridades

1. Finalizar a modelagem conforme o PDF da Entrega 2.
2. Garantir que todas as chaves primárias e estrangeiras estejam coerentes.
3. Implementar as nove entidades no banco.
4. Inserir dados de teste.
5. Executar as consultas e verificar os resultados.
6. Executar os testes e registrar evidências.
7. Corrigir inconsistências encontradas.
8. Atualizar a documentação final.

## 4. Critérios de conclusão

A etapa de modelagem será considerada concluída quando:

* existirem as nove entidades definidas no PDF;
* cada entidade possuir sua chave primária;
* as chaves estrangeiras representarem os relacionamentos definidos;
* as cardinalidades do DER estiverem de acordo com o documento;
* o modelo lógico e o SQL estiverem consistentes;
* os testes de integridade do banco forem executados e registrados.

> Observação: o PDF da Entrega 2 não apresenta um cronograma com datas. Portanto, este planejamento organiza as etapas do projeto sem inventar datas que não foram fornecidas.
