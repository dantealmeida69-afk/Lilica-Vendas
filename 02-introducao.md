# 02 introducao

## Apresentação geral

O **Lilica Vendas** é um sistema web responsivo para pequenos comércios. Ele permite cadastrar produtos e clientes, registrar vendas, controlar o estoque automaticamente, acompanhar pagamentos e consultar relatórios de desempenho.

O diferencial é o **Assistente Lilica**, um recurso de Inteligência Artificial que lê os números do negócio e devolve **resumos em linguagem simples** e **sugestões práticas**, como quais produtos repor e quais tiveram queda de vendas.

## Contexto

O projeto foi desenvolvido na atividade **A3 — IA para o Cotidiano**, da Unidade Curricular **Qualidade de Software**. O trabalho é documentado neste GitBook, do problema até a demonstração para a banca.

## Como o sistema funciona, em resumo

1. O vendedor entra no sistema com seu login.
2. Escolhe o cliente (ou faz uma venda de balcão) e adiciona os produtos.
3. O sistema confere o estoque, calcula o total e registra o pagamento.
4. O estoque é atualizado automaticamente.
5. O dono acompanha vendas, produtos mais vendidos e estoque baixo nos relatórios.
6. O Assistente Lilica resume o período e sugere ações.

## Onde a IA entra

| Frente                 | Uso                                                                                                                                        |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| **No sistema**         | Assistente Lilica: resumos de vendas e sugestões de reposição e de ação, a partir de dados **agregados** (sem dados pessoais de clientes). |
| **No desenvolvimento** | Apoio à prototipagem, à programação, à modelagem do banco e à geração de dados fictícios para testes.                                      |
