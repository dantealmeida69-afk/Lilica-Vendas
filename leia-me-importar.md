# LEIA ME IMPORTAR

A pasta `gitbook/` contém o livro (capa + 21 seções do roteiro + 3 imagens). Eu não tenho acesso de escrita à sua conta do GitBook, então a importação é feita por você.

## Opção A — Git Sync com GitHub (recomendada)

1. Crie um repositório no GitHub e envie o conteúdo deste zip, mantendo `.gitbook.yaml` na raiz e a pasta `gitbook/`.
2. No GitBook, crie um **space novo** (não use o do projeto de saúde) → **Configure → Git Sync** → conecte ao repositório.
3. Na primeira sincronização escolha **GitHub → GitBook**.

## Opção B — Colar página por página

Abra cada `.md` e cole no editor. Blocos `{% hint %}` só viram caixas coloridas pelo Git Sync; ao colar, troque por um bloco "Hint". As imagens estão em `gitbook/.gitbook/assets/` (der.png, arquitetura.png, fluxo-venda.png).

## Atenção: o conceito foi suposto

Assumi que o **Lilica Vendas é um sistema web de gestão de vendas para pequeno comércio** (produtos, clientes, pedidos, estoque, pagamentos, relatórios e um assistente de IA). Se o seu projeto for diferente, os pontos mais afetados são: páginas 03, 06, 07, 08, 09–13 e 16. O catálogo de exemplo (camiseta, caneca etc.) é fictício.
